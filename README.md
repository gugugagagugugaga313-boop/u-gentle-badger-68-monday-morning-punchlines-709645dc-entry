One joke about Monday mornings, at most 200 characters, written by a small
deterministic program for the [Monday Morning Punchlines](https://make.fun/competitions/u-gentle-badger-68-monday-morning-punchlines-709645dc)
competition on make.fun.

## The joke

> Monday morning, my bed promoted me: from lying down to lying to myself about getting up.

## How it works

`main.ts` (Node 22) writes that exact joke — and nothing else — to
`/output/entry.txt`. The joke is a fixed string in the program, so every
run produces byte-identical output. No network, no randomness, no input.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
